Roadmap do Fileserver

v1.0 (Versão Atual)

UI moderna responsiva, IP da LAN com botão copiar, upload drag & drop para X:\Shared\uploads, ordenação, preview inline e sem dependências externas.

v1.1

Exclusão e renomeação de arquivos com diálogo de confirmação, múltiplos uploads concorrentes e melhorias de performance.

v1.2

FTP integrado funcionando (toggle do menu Ferramentas liga de verdade o serviço), aceitando conexões de clientes legados.

v1.3

Gerenciador de arquivos visual estilo FileZilla: interface de duas colunas com arrastar-e-soltar e sincronização em tempo real.

v2.0

App móvel nativo em React Native + NativeWind consumindo os endpoints REST definidos nesta versão (/api/info, /api/list, /upload, /files).
